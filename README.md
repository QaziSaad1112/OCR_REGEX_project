Invoice OCR + Regex

A small project where I read text from an invoice image using OCR and pick out details like invoice number, country and costs using Regex.

Tools: Python, pytesseract, Pillow, Regex

How to run: Install Tesseract and pip install pytesseract pillow, then open the notebook and run all cells.

Note: The sample invoice is a blank template, so the output shows placeholder text.
